# DINTEGI Landing v2

Landing institucional premium para **DINTEGI Soluciones Digitales**.

## Probar localmente

```bash
npm install
npm run dev
```

Abrir:

```txt
http://localhost:5173
```

## Generar producción

```bash
npm run build
```

La carpeta final para publicar queda en:

```txt
dist/
```

## Publicación recomendada en Cloudflare Pages

1. Subir el proyecto a GitHub.
2. En Cloudflare Pages: crear proyecto conectado al repositorio.
3. Build command:

```bash
npm run build
```

4. Output directory:

```txt
dist
```

5. Conectar dominios:

```txt
dintegi.com.ar
www.dintegi.com.ar
```
